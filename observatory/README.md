# AI Observatory — research and intelligence layer

This is not a separate AI-industry database filled with invented companies. **OpenAI** is the first actual company investigated. The current source list, observations, claims, unknowns, and relationships are in `companies/openai/`.

- `sources.csv`: primary source ID, path/link, observed date, snapshot vs live status and limits.
- `observations.csv`: source-grounded observation and evidence state.
- `claims.csv`: statements classified DOCUMENTED/CORROBORATED/REPORTED/INFERRED/HYPOTHESIS/UNKNOWN/SUPERSEDED.
- `relationships.csv`: explicit company/role/skill/source/evidence links with evidence state.
- `CASE_FILE.md`: readable company, hiring and application investigation with open questions.

Longer term: company/products/models/people/technologies and their relations, cross-company metrics, market-directed curriculum, industry investigations and a public Observatory. Graph database and UI are not prerequisites; a referenced CSV relation is already a concrete first graph record.
