# ProofLoop shared framework: actual minimum for Attempt #001

This is a **reusable v0.1 operational model**, not a claim of complete automation or a production-ready application tracker. It belongs to the journey root; `Day1` remains the actual first engineering case.

| Record | What it captures |
|---|---|
| `applications.csv` and `application_events.csv` | Canonical per-target status and observed lifecycle events |
| `requirements.csv`, `evidence.csv`, `proof_graph.csv` | Requirement source, available evidence and gaps (simple Proof Graph) |
| `skills.csv`, `learning_log.csv` | Capability evidence states and just-in-time learning |
| `build_log.csv`, `decisions.csv` | Work, verification, genuine failures, project/creative decisions |
| `time_log.csv` | Real elapsed effort if measured; unknown remains blank |
| `ai_reviews.csv` | AI prompts, handoffs, limitations and independently checked decisions |

Source-grounded employer observations and claims are kept in `observatory/`; technical implementations, tests, datasets and interface remain in the existing `Day1/FinalVersion` folder. Templates are deliberately simple. Date fields are blank until supported; initial sample rows are traceable, explicitly retrospective when needed, and not fictional submissions.

See `docs/WORKFLOW.md` for IDs, joining records and closing actual application cycles.
