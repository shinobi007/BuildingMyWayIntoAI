# Technical and creative decisions as project evidence

Use `framework/ledgers/decisions.csv` to record actual choices, reasons, evidence, alternatives and reversibility.

Examples of **documentable prior choices**: retaining both source and normalized forms; SQLite for the first local database; stage-by-stage validation; corrective Windows regression tests; a read-only local interface; separating remote metadata from work-from-Utah eligibility; Stage 9 as portable independent prompt; one root Git repository. Retrospective entries must be labeled as such.

Capture **why** a design emerged and what failed, not only what Python script was run. Design choices demonstrate information architecture, research methodology, engineering judgment and project management alongside technical implementation.
